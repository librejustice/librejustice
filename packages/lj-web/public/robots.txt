# LibreJustice — politique d'accès des crawlers
#
# Moteur de recherche libre sur la jurisprudence française (administrative et judiciaire).
#
# Enforcement technique : règles WAF Cloudflare (cf. zone librejustice.fr).
# Ce fichier expose le signal d'intention conformément à l'article 4 de la
# directive (UE) 2019/790 sur le droit d'auteur — il est complémentaire,
# pas substitutif. Bytespider et autres non-compliants sont bloqués au WAF.
#
# Politique :
# - Search engines (Google, Bing, DuckDuckGo)        : autorisés
# - User-initiated AI fetch (ChatGPT, Claude, etc.)  : autorisés
# - AI search / answer engines avec citations         : autorisés
# - AI training (collecte pour pré-entraînement)      : refusés
# - Scrapers commerciaux SEO / brand monitoring       : refusés

# Signal Content-Signals (https://contentsignals.org) — directive EU 2019/790
User-agent: *
Content-Signal: search=yes, ai-input=yes, ai-train=no
Allow: /
